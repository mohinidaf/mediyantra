# MediYantra

MediYantra is a healthcare management web application developed for the Spark to Solution Hackathon.

## Features
- 🏥 Real-time Hospital Bed Availability
- 🚑 Ambulance Tracking
- 📅 Appointment Booking
- 👨‍⚕️ Doctor & Treatment Search
